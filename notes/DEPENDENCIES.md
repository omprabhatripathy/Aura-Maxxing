## Browser APIs relied on

`localStorage`/`sessionStorage` (local mode, timer, theme, reminder de-dup), `Notification` API, Web Audio (Pomodoro chime), `crypto.subtle` (local password hashing), `matchMedia` (device and reduced-motion detection), Canvas (charts, avatar resize).

## Updating

```bash
npm outdated
npm update            # within ranges
npx tsc -p tsconfig.app.json --noEmit && npx eslint src && npx vitest run && npm run build
```

Watch for: Firebase major versions (Firestore cache API), react-router majors, `eslint-plugin-react-hooks` rule changes (it has flagged several patterns in this codebase before).
