# Known Issues

Last reviewed: 2026-11-01. Severity: 🔴 high · 🟠 medium · 🟢 low.

## Current bugs / operational risks

| #   | Sev | Issue                                                   | Detail                                                                                                                                                                                                                                                                                                                                      | Fix                                                                                                 |
| --- | --- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 1   | 🔴  | Cloud mode needs the Firestore database + current rules | If the Firestore API/database is not created in project `aura-maxxing-cd7be`, or `firestore.rules` is not redeployed after adding collections (`pomodoro`, `expenses`, `income`, `schedule`, `settings/finance`), writes are rejected or stay queued. `commit` stops waiting after 4 s so the UI does not hang, which can hide the problem. | Create the database, run `firebase deploy --only firestore:rules` ([DEPLOYMENT.md](DEPLOYMENT.md)). |
| 2   | 🟠  | Pomodoro history capped at 1,000 sessions               | `DataProvider` subscribes to the newest 1,000 `pomodoro` docs (500 legacy focus sessions). All-time stats and the _Focus Legend_ achievement (3,000 min) only see that window.                                                                                                                                                              | Store running totals (e.g. in `taskStats`-style daily docs) or raise/paginate.                      |
| 3   | 🟠  | Reminders only run while the app is open                | `AppReminderRunner`, `ScheduleReminderRunner`, `PeriodReminderRunner` use `setInterval` in the page. Closed tab = no reminder.                                                                                                                                                                                                              | Service worker + Firebase Cloud Messaging.                                                          |
| 4   | 🟠  | Pomodoro timer is per device                            | State lives in `localStorage['aura-pomodoro-timer']`; starting on phone and finishing on desktop is not possible.                                                                                                                                                                                                                           | Persist an "active session" doc in Firestore.                                                       |
| 5   | 🟢  | Delete-all-data is partial                              | `deleteAllUserData` removes all collections but keeps `users/{uid}`, the Auth account, Storage files and the `phoneIndex/{mobile}` entry.                                                                                                                                                                                                   | Add account deletion (Auth + Storage + phoneIndex).                                                 |
| 6   | 🟢  | Dates are local-time strings                            | A user changing time zone can see a day shift for streaks/logs near midnight.                                                                                                                                                                                                                                                               | Store the user's time zone in preferences.                                                          |
| 7   | 🟢  | Google sign-in not declared in `firebase.json`          | Only `emailPassword` is listed; Google must be enabled manually in the console, and every hosting domain must be an authorised domain.                                                                                                                                                                                                      | Document/automate in the deploy checklist.                                                          |

Merge Todo data into `DataProvider` or share the subscription.                                                               |

## Performance bottlenecks

| #   | Area                               | Measurement / cause                                                                                                                                                           | Opportunity                                                                                                                                         |
| --- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1  | Bundle size                        | Production build: `ops-*.js` 754 kB (229 kB gzip — Firebase SDK), `index-*.js` 422 kB (129 kB gzip — React, router, chart.js, shared code). Vite warns about chunks > 500 kB. | `build.rolldownOptions.output` manual chunks for `firebase/*`; lazy-load Storage (only used for uploads); lazy-load chart.js with chart components. |
| P2  | Full recomputation on every change | Any write re-runs `buildReport` (2 radars) + `buildProgression` (XP ledger over all history). Cheap today, grows linearly with history.                                       | Memoise per-collection partial results; compute XP incrementally per day.                                                                           |
| P3  | Analytics radar history            | `AuraRadarPanel` computes up to ~25 historical radars (monthly cached; weekly/yearly on demand).                                                                              | Use stored `analyticsSnapshots` for past points when available.                                                                                     |
| P4  | Unbounded collections              | `expenses`, `income`, `schedule`, `habitLogs`, `journalEntries`, `moodLogs` are subscribed without a limit.                                                                   | Window by date (e.g. 400 days) and paginate history views.                                                                                          |
| P5  | `emojilib` chunk                   | 174 kB (49 kB gzip), lazy-loaded only when the emoji picker opens — acceptable.                                                                                               | —                                                                                                                                                   |

## Improvement opportunities

- Store per-day aggregates server-side (Cloud Functions) to keep clients light.
- Offline write queue indicator ("3 changes waiting to sync").
- Accessibility pass on the radar canvas (keyboard focus per area — the breakdown list is the accessible alternative today).
- Internationalisation (currency formatting is per user; dates/labels are English only).
